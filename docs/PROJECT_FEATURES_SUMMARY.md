# AI 求签解签系统功能与架构说明

## 1. 项目定位

本项目是一个融合黄大仙灵签知识库、Chroma RAG 检索、Qwen 大模型、五维运势评分、相似签推荐和用户画像分析的 AI 解签系统。系统并不直接预测现实结果，而是基于传统文化文本进行娱乐化解释、自我反思和结构化建议生成。

## 2. 核心流程

用户进入系统后，先输入想咨询的问题，并选择问题方向和解签风格。点击开始摇签后，系统调用后端抽签接口生成签卡。用户点击签卡后，系统才正式进入解签阶段，后端会进行签文知识检索、大模型结构化解读、五维运势评分、相似签推荐和历史记录更新，最终在前端生成完整解签报告。

整体流程为：

用户输入问题 → 后端抽签 → 前端展示签卡 → 用户点击签卡 → RAG 检索 → Qwen 结构化解签 → 五维雷达分析 → 相似签推荐 → 用户画像更新 → 报告页展示。

## 3. 后端模块

- fortune_drawer.py：负责后端抽签逻辑。
- fortune_retriever.py：负责从 Chroma 知识库中检索签文片段。
- fortune_prompt.py：负责构造结构化解签 Prompt。
- fortune_ai.py：负责问题理解、结构化 JSON 解签结果解析和兜底处理。
- llm_client.py：负责调用本地 Qwen/vLLM 大模型服务。
- fortune_radar.py：负责生成事业、学业、感情、财运、健康五维运势评分。
- fortune_similarity.py：负责基于语义相似度推荐相似签。
- fortune_history.py：负责记录求签历史并生成用户画像统计。
- routes/fortune.py：提供 draw、interpret、profile 等后端接口。

## 4. 前端模块

前端采用两阶段交互：

第一阶段是求签页，只负责问题输入、方向选择、风格选择和摇签动画。第二阶段是解签报告页，集中展示核心解读、数据分析、传统签文、检索依据、相似签推荐和用户画像。

## 5. 数据处理与模型设计

系统首先将黄大仙灵签文本进行结构化整理，并写入 Chroma 向量数据库。解签阶段根据签号、用户问题和问题方向进行检索，得到相关签文片段作为大模型生成依据。系统进一步设计五维评分模型，将签级、关键词和方向信息转化为事业、学业、感情、财运、健康五个维度的数值评分，并通过雷达图进行可视化展示。

## 6. AI 解签设计

系统将 AI 解签从自由文本生成改为结构化 JSON 报告生成。大模型需要输出白话总结、传统签意、针对问题的回答、行动建议、风险提醒、安抚提示和一句话结论。后端会对输出字段进行解析和兜底，保证前端展示稳定。

## 7. 可视化功能

系统包含五维运势雷达图、维度分数条、RAG 检索依据分数、相似签推荐卡片、用户画像统计图和历史趋势信息，用于增强项目的数据处理和可解释性展示。
